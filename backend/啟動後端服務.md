# 🚀 如何啟動後端服務

## 方法 1：使用啟動腳本（推薦）

### 選項 A：背景運行（無視窗）
雙擊執行：
```
backend/start-backend-hidden.vbs
```
- ✅ 在背景運行，不會顯示視窗
- ✅ 適合日常使用
- ⚠️ 要停止服務需要從工作管理員結束 Python 程序

### 選項 B：顯示視窗（可看到運行狀態）
雙擊執行：
```
backend/start-backend-persistent.bat
```
- ✅ 顯示運行狀態和日誌
- ✅ 可以看到錯誤訊息
- ✅ 關閉視窗即停止服務
- 💡 **推薦用於測試和除錯**

## 方法 2：手動啟動

### 步驟 1：開啟命令提示字元
1. 按 `Win + R`
2. 輸入 `cmd` 並按 Enter

### 步驟 2：進入後端目錄
```bash
cd /d D:\CODE\4-WEBGPU-02\construction-safety-extension\backend
```

### 步驟 3：啟動服務
```bash
python app.py
```

或使用 Python 3：
```bash
python3 app.py
```

## ⚠️ 常見問題

### 問題 1：找不到 Python
**錯誤訊息**：
```
'python' 不是內部或外部命令，也不是可執行的程序或批次檔。
```

**解決方法**：
1. 確認已安裝 Python 3.10+
2. 將 Python 加入 PATH 環境變數
3. 或使用完整路徑：
   ```bash
   C:\Python310\python.exe app.py
   ```

### 問題 2：缺少依賴套件
**錯誤訊息**：
```
ModuleNotFoundError: No module named 'fastapi'
```

**解決方法**：
```bash
cd backend
pip install -r requirements.txt
```

### 問題 3：找不到 YOLO 模型
**錯誤訊息**：
```
❌ Model file not found: models/best_yolo11x.pt
```

**解決方法**：
```bash
cd backend
python download_model.py
```

### 問題 4：端口被佔用
**錯誤訊息**：
```
OSError: [Errno 48] Address already in use
```

**解決方法**：
1. 關閉佔用 8000 端口的程序
2. 或修改 `app.py` 使用其他端口（例如 8001）

## 🔧 自動啟動設定（選用）
